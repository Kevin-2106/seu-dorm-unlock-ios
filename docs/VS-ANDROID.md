# 与 Android 版（上游）的对照

← [返回 README](../README.md)

本项目是 [Haa1024/SEU-Door-Unlock](https://github.com/Haa1024/SEU-Door-Unlock) 的 iOS 实现。**协议层移植自它**，但这不是 Android 版的完整复刻：只移植了"登录 → 取凭据 → 开门"这条主路径，界面是独立设计的，另外加了一些 iOS 专属的能力。

## 协议层：移植

下面这些是对上游 Kotlin 实现的**逐函数移植**：

- 加密：CRC8（多项式 `0x07`）、RC4、设备密钥派生
- BLE 帧：`0x74`（凭证头）、`0x75`（凭证分包）、`0x78`（开锁）、`0x76` / `0x77`（向锁索取新钥匙）
- NFC 帧：`0xB1`
- 错误码处理、密钥轮换、凭据自动刷新的分支结构

**怎么验证移植是对的**：用独立的 Kotlin 工具链和 Swift 工具链各跑一遍同样的输入（`deriveDeviceKey`、CRC8、RC4、各类 BLE / NFC 帧的构造与响应解析），生成测试向量，**字节级比对完全一致**。这是整个移植里最容易出隐蔽错误的部分，所以先单独验证。

协议本身的细节（帧格式、密钥派生、结果码）请看上游的 [README-NFC.md](https://github.com/Haa1024/SEU-Door-Unlock/blob/main/README-NFC.md)，这里不重复。

## 没有移植的

| 上游功能 | 这里的情况 |
|---|---|
| 支付宝一键登录 | ❌ 只有手机号 + 密码 |
| NFC 磁贴写卡 / 碰磁贴触发 BLE 开门 | ❌ |
| 读 NDEF / 用标签 UID 反推设备号（上游仅作诊断用途） | ❌ |
| 旧的"在线重置离线计数器"方案（上游自己已标注废弃） | ❌ |
| 占用官方包名的变体及相关说明 | ❌ 不涉及，本项目不占用任何官方包名 |
| 手动填写 MAC 地址直连 | ⚠️ iOS 拿不到真实 MAC，改用蓝牙外设 UUID 缓存 |
| 东南大学 VIS 配色与界面 | ❌ 界面是独立设计的，没有沿用 |
| NFC 路径的自动刷新凭据 | ❌ 上游也没有，NFC 失败只提示 |

## iOS 上做不到、或不同的

这些是**平台限制**，不是没做。

### 碰一下锁就自动打开 App：做不到

上游靠 Android 的后台 NFC 分发：门锁标签里指名了官方包名，系统在碰到标签时直接把它交给那个 App，即使 App 不在前台。

iOS 没有对应机制：

- 读这种标签需要**原始帧收发**（`NFCMiFareTag.sendMiFareCommand`），这只能在 App **前台**的读卡会话里做，并且每次都会弹出系统的"准备扫描"面板；
- iOS 的**后台标签读取**只在 iPhone XS 及以上可用，且只处理标准的 NDEF 内容，由系统根据内容决定打开哪个 App。对这把锁来说，标签里指向的是官方 App 的域名，第三方无法抢占。

所以在 iOS 上的用法是：**先打开 App，或点锁屏小组件 / Action 按钮 / 快捷指令，然后再贴锁**。见 [USAGE.md](USAGE.md)。

### NFC 需要特殊权限，侧载通常拿不到

见 [NFC-AND-SIDELOADING.md](NFC-AND-SIDELOADING.md)。TrollStore / 越狱 / 付费账号可以；SideStore + 免费 Apple ID、LiveContainer 不行。

### 没有后台蓝牙

只在前台工作。锁屏小组件的作用是**唤起 App 再开门**，不是在小组件进程里直接开——扩展进程里跑蓝牙既不稳定也受时长限制。

### 小组件是纯静态的

不读 App 的数据（比如不显示设备号），也不使用 App Group。SideStore 对免费账号会改写 App Group 的 ID，容易出问题，所以干脆不用。Android 版的桌面小组件可以拖放调整大小，iOS 这里是系统规定的固定尺寸。

### 读卡每次都有系统面板

Android 可以无界面读卡。iOS 的 `NFCTagReaderSession` 每次都会弹出系统面板，无法关闭。

### 蓝牙底层参数不可控

CoreBluetooth 不暴露 MTU 协商、真实 MAC 地址等底层信息。所以没有"填 MAC 直连"，改用外设 UUID 缓存。

## iOS 版新增的

| 功能 | 说明 |
|---|---|
| 蓝牙外设 UUID 缓存直连 | 第一次成功后记住，之后跳过广播扫描；失败自动回退 |
| 打开 App 即进入 NFC 持续监听 | 前台自动监听，开完继续；可关；系统面板点取消后不再自动重开 |
| 默认开门方式 | 蓝牙 / NFC 二选一，另一种作为备选小按钮 |
| 失败原因与补救 | 中文错误提示，一键重新拉取凭据 |
| 开门中取消 | 再点一下按钮取消 |
| 开锁记录 | 时间 / 方式 / 结果 / 耗时 / 平均耗时 |
| 诊断页 | 日志复制自动打码 |
| 锁屏 / 主屏小组件 | 点按唤起 App 并自动开始蓝牙开门（iOS 16+） |
| 锁屏控制 | 可替换锁屏角落按钮、加入控制中心（iOS 18+） |
| 快捷指令「开门」动作 | 内置在主 App，不依赖扩展；Action 按钮、轻点背面、Siri |
| 配置码 | 导出 / 导入开门凭据（不含账号密码），免去每台设备都登录（⚠️ 已知问题见 [VERIFICATION.md](VERIFICATION.md)） |
| iOS 26 Liquid Glass 适配 | 低版本自动退回常规材质 |
| 开门过程的视觉与触感反馈 | 蓄力 / 成功 / 失败；CoreHaptics |
| 自定义背景图、可调参数页 | 设置页「视觉与震动调节」 |
| 构建信息与扩展检测 | 首页底部与设置页「关于」显示版本 / 构建号 / commit，并检测小组件扩展是否装上 |
