## 设置页结构

首页右上角齿轮进入设置，首页分类：

| 页面 | 内容 |
|---|---|
| 门锁 | 账号登录 / 重新拉取凭据、配置码导出导入；「手动编辑门锁参数」在子页里，保存前要确认 |
| 开门方式 | 默认方式（蓝牙 / NFC）、打开 App 时是否自动 NFC 扫描、重置蓝牙缓存 |
| 外观与反馈 | 首页背景（压暗 / 模糊）、视觉与震动调节（三档预设、自动精简、各细项子页） |
| 开锁记录 | 每次开门的时间、方式、结果、耗时，及平均耗时 |
| 诊断 | 蓝牙 / NFC / 网络日志，复制（自动打码）和清空 |
| 关于 | 版本、构建号、小组件扩展是否安装、凭据存储位置 |

## 入口 1：App 内点「开门」

1. 打开「门钥」，首页中间是开门按钮，上方是当前门锁（`XN-设备号`）。
2. 点按钮：App 会依次**扫描 → 连接 → 发送凭据 → 开锁**，状态卡片实时显示进度。
3. 结果：
   - 成功：绿色闪光、粒子向外炸开，震动是类似支付成功的双击；
   - 失败：红色闪光、按钮抖动，震动是两下强抖，状态卡片写明原因。

**取消**：开门过程中（扫描、连接、传凭据阶段）再点一下按钮即可取消，不算失败。开锁命令一发出就不能再取消，避免"显示已取消但门其实开了"。

**失败时**：状态卡片会写明原因，并按情况给按钮：
- 凭据过期 / 离线次数用完 / 锁不认凭据 → 「重新拉取凭据」（用已保存的账号，优先复用会话，必要时才重新登录）；
- 还没登录过 → 「去登录」。

**默认方式**：设置 → 开门方式 → 默认开门方式。它决定大按钮、锁屏小组件 / 控制、快捷指令用蓝牙还是 NFC；另一种在首页底部是小按钮（「改用 NFC 开门」/「改用蓝牙开门」）。设备或安装方式不支持 NFC 时只能选蓝牙。

**首次使用**：没配置时按钮是「去登录」；配置好后首页有三步上手清单，点「完成」后消失。

第一次成功连接后，App 会记住这把锁的蓝牙标识，之后开门直接连接，不再等待广播扫描（连不上会自动回退扫描）。

## 入口 2：锁屏小组件 / 锁屏控制

### 锁屏小组件（iOS 16+）

1. 长按锁屏 → **自定义** → 选择「锁定屏幕」。
2. 点**时间下方**的小组件栏（或时间上方的一行）。
3. 搜索「门钥」，选择样式：**圆形**、**矩形**、**行内**。主屏也可以添加小号小组件。
4. 在锁屏**点一下小组件**：系统要求先解锁（Face ID / Touch ID / 密码），解锁后「门钥」打开并**自动开始蓝牙开门**。

### 锁屏控制（iOS 18+）

1. 长按锁屏 → **自定义** → 点左下 / 右下角的按钮。
2. 选择「门钥 · 开门」控制，替换原来的手电筒 / 相机。
3. 同一个控制也可以加到**控制中心**。

> 小组件是静态的，它**只负责唤起 App**，真正的蓝牙开门在 App 里进行——扩展进程里跑蓝牙既不稳定也受时长限制。所以点按之后一定会看到 App 打开。

> 如果在添加列表里找不到「门钥」，多半是侧载时扩展被移除了（免费 Apple ID 的 App ID 额度不够）。到设置页「关于」看"小组件扩展"是否为"已安装"，详见 [INSTALL.md](INSTALL.md#小组件扩展没装上)。

## 入口 3：Action 按钮与快捷指令

「开门」动作内置在 App 本体里，**不依赖小组件扩展**，所以即使扩展没装上也能用。

### 绑定 Action 按钮

适用于带 Action 按钮的机型。

1. **设置 → 操作按钮**。
2. 滑到「快捷指令」，点「选取快捷指令」。
3. 在列表里找到「门钥」下的**「开门」**。
4. 之后按下 Action 按钮：App 打开并立即开始开门。

### 其他触发方式

在「快捷指令」App 里，「门钥」的「开门」动作可以：

- 放到**锁屏 / 控制中心的快捷指令控件**；
- 绑定**轻点背面**（设置 → 辅助功能 → 触控 → 轻点背面）；
- 用 **Siri**：「用门钥开门」或「门钥开门」；
- 添加到主屏，或加入自动化。

快捷指令的使用方法见 Apple 官方的[快捷指令用户指南](https://support.apple.com/zh-cn/guide/shortcuts/welcome/ios)。

> 冷启动时（App 没在后台）快捷指令可能比 App 界面先执行，App 内做了补偿：界面出现后会补上这次开门请求。

## NFC 碰锁

**前提**：安装方式必须能带上 NFC 权限（TrollStore / 越狱 / 付费开发者账号），见 [NFC-AND-SIDELOADING.md](NFC-AND-SIDELOADING.md)。免费账号 + SideStore 装的话，首页会提示"此设备不支持 NFC 读卡"，蓝牙不受影响。

使用方式：

1. 打开 App，已经配置好凭据的话会**自动进入持续监听**（首页底部显示"NFC 持续监听中，碰锁即开"，旁边有「停止」）。不想自动弹出，可在 设置 → 开门方式 关掉「打开 App 时自动 NFC 扫描」，关闭会立刻停止当前监听，首页仍有「改用 NFC 开门」按钮可手动开始。
2. 把手机背面贴近门锁感应区。系统会弹出 NFC 读卡面板，读到后自动完成开门。
3. 开完自动继续监听。退到后台会停止，回前台再自动开始。
4. 在系统 NFC 面板上点「取消」后，本次不会再自动弹出；退到后台再回来，或手动点「改用 NFC 开门」才会重新开始。

**为什么必须先打开 App**：iOS 不允许第三方 App 在后台 / 锁屏读取这类标签，读卡只能在前台进行。和 Android 的区别见 [VS-ANDROID.md](VS-ANDROID.md)。

**从小组件 / 快捷指令进入时**：默认方式是蓝牙就直接走蓝牙（并跳过 NFC 监听，避免系统面板盖住屏幕）；默认方式设成 NFC 就直接弹 NFC 面板。

**密钥轮换**：每次 NFC 开门成功，锁会返回一把新的 chainKey，App 自动保存。

## 配置码（多设备）

在设置页：

- **导出配置码到剪贴板**：把当前的开门凭据（设备号、项目号、凭据号、chainKey）编码成一段文本。**不含账号密码**。配置码相当于钥匙，**60 秒后由系统自动从剪贴板清除**，别发给别人。
- **从剪贴板导入配置码**：在另一台设备粘贴导入，免去再登录一次。

> ⚠️ **已知问题**：实测导入的配置码**可以导入成功，但之后凭据似乎会失效**。推测与 NFC 开门时锁会更换 chainKey 有关（旧钥匙随之作废），但具体原因没有查实。建议当作备用 / 一次性迁移，失效时在那台设备上点「用已保存的账号重新拉取」或重新登录。详见 [VERIFICATION.md](VERIFICATION.md)。

## 视觉与震动参数

设置 → 外观与反馈 → **视觉与震动调节**。顶部有「克制 / 标准 / 炫酷」三档动效预设（只改动效强度，不动按钮样式、背景、震动开关），选完仍可在子页里微调。所有滑块直接生效，不用重启：

| 分组 | 可调内容 |
|---|---|
| 按钮与圆环 | 按钮样式（玻璃实心 / 玻璃透明 / 实色 / 描边透明）、实色不透明度、玻璃透明的状态色强度、暗色衬底、圆环粗细 / 亮度、反转圆环方向 |
| 陀螺仪 | 倾斜 / 视差强度（0 = 关闭） |
| 开门中（蓄力） | 蓄力时长、背景变暗程度、bloom 泛光、RGB 分离、成功 / 失败闪色强度 |
| 涟漪 | 数量、速度、扩散距离、最大不透明度 |
| 粒子 | 环境尘埃数量、粒子大小、跃迁粒子数量 / 速度 / 拖尾长度 |
| 震动 | 开关、搜索嗡鸣强度与锐度、成功 / 失败强度，另有三个"试震"按钮 |

如果觉得发热或掉帧：把粒子数量、涟漪数量调低，或把 bloom 调到 0。

**自动精简**：开启「低电量 / 减弱动态时自动精简」（默认开）后，系统开了低电量模式或「减弱动态效果」时，首页自动关闭粒子、涟漪、陀螺仪视差、RGB 分离、待机呼吸和失败抖动，闪色和震动保留。

首页背景图：设置 → 外观与反馈 → 选择背景图片（需要 iOS 16+）；设了图之后可调「额外压暗」和「模糊」，亮图上白字看不清时调高压暗。

震动用的是 CoreHaptics，**iPhone 8 及以上**才有；iPhone 7 自动回退到系统震动，强度 / 锐度滑块对它无效。
